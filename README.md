# Shayne Magstadt Portfolio

This folder is ready for GitHub Pages. Upload everything inside it to the root of the `ShayneGeo.github.io` repository, replacing the older site files, and commit the changes.

## Replace the portrait later

Export the new portrait as a landscape JPG named `portrait-placeholder.jpg` and replace `assets/portrait-placeholder.jpg`. No code changes are needed. If the crop needs adjustment, search `styles.css` for `.portrait img` and change `object-position`.

## Main files

- `index.html` contains the biography, eight-paper research library, and marble gallery.
- `styles.css` contains the visual design and responsive layouts.
- `script.js` controls the tabs, research filters, paper overviews, and marble lightbox.
- `papers/` contains the downloadable research PDFs.
- `files/` contains the downloadable CV.

All links are relative. The site runs directly on GitHub Pages with no build step, framework, or external dependency.
